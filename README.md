## Projetos

| Projeto | O que é | Tecnologias |
|---|---|---|
| **Sistema do Laboratório 3D** *(privado, estágio)* | Pedidos, fila de produção, catálogo, precificação e vendas de peças 3D, com um bot de WhatsApp de 3 agentes de IA na entrada. 2.300+ testes automatizados. | Python, FastAPI, PostgreSQL, Docker, n8n, OpenAI |
| [**FindBus**](https://findbus.com.br) | Painel em tempo real que mostra quais ônibus da RMTC (Goiânia) têm ar-condicionado. 12,6 mil visitas por mês, com cache em 3 camadas. | FastAPI, Redis, Cloudflare, Docker, Leaflet |
| [**Extrator de faturas**](https://github.com/MatheusBraga1106/extrator-faturas-agua) | PDF de conta de água → dados estruturados para auditoria de órgãos públicos, com OCR, interface web e testes automatizados. | Python, pandas, FastAPI, PostgreSQL, Tesseract |
| [**Robô desviador**](https://github.com/MatheusBraga1106/robo-desviador) | Simulador de um robô real (motores DC + HC-SR04): você joga e a sua rede neural joga, treinada por neuroevolução. | Python, pygame, Arduino |
| [**Hub Sim Racing**](https://github.com/MatheusBraga1106/hub-sim-racing) ([site e download](https://matheusbraga1106.github.io/hub-sim-racing/)) | App desktop para base de força, volante DIY, câmbio Wi-Fi e pedais, com cena 3D do volante. 9 versões publicadas. | Python, FastAPI, WebSocket, pywebview, Three.js |
| **Monitor do mercado de confiança** *(privado)* | Câmera e sensores na geladeira sem atendente do Centro Acadêmico da UFG, com painel de auditoria. | ESP32-S3, painel web |
| [**3d-web-dev-skills**](https://github.com/MatheusBraga1106/3d-web-dev-skills) | Guia técnico em português para interfaces web com 3D servidas por Python. Funciona como skill do Claude Code. | Three.js, FastAPI, pywebview |
